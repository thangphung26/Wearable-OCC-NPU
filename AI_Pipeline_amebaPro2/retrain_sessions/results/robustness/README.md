# Repeat-3 offline robustness

Run from repository root: `.venv/bin/python 1_VLC_code_main/AI_Pipeline_amebaPro2/retrain_sessions/robustness.py`.
Use `--sanity-only` to regenerate and compare without writing outputs or importing TensorFlow. TensorFlow is forced to CPU before import. No training or LOSO access occurs.
Plot completed training runs with `.venv/bin/python 1_VLC_code_main/AI_Pipeline_amebaPro2/retrain_sessions/plots.py repeat lodo`.

All eight repeat-3 sessions are retained (800 frames, 38,400 bits); the 1–5 m subset has six sessions (600 frames, 28,800 bits). The 7 m legacy-gray provenance remains in CSV. Capture acquisition is 30 FPS; buffered resampling is 20 Hz; link rate is 5 bit/s.
Raw capture `samples.json` supplies the signal; capture `frame_decisions.json` supplies the original nominal TX timing; `tx_ground_truth.json` supplies truth matched by frame ID and checked against replay truth. Imported `PreambleTracker.align`, `manchester_phase.refine`, replay `sample`, and `benchmark_precrc.normalize` regenerate each float window. No payload-dependent timing search is introduced. Sanity must pass before any outputs are produced: at least 99% whole INT8 windows and 99.9% Classic bits must match stored replay decisions.

`float_windows.npz` contains the pre-normalization float64 windows, truth, session/frame IDs, and aligned start times. `results.csv` contains every evaluated window/realization with error positions, counts, and exact-window indicators for all three decoders. `summary.json` contains pooled and subset counts, BER, two-sided 95% Clopper–Pearson intervals, exact windows, and per-realization all-distance counts. Pooled noise-condition BER equals the arithmetic mean of five realization BERs; `mean_errors_per_realization` also reports the mean error count. Noise-condition denominators are 192,000 bits / 4,000 windows (all) and 144,000 bits / 3,000 windows (subset). These are repeated evaluations of the same held-out frames, not additional captured frames.

Timing offsets are added to sampling instants after coarse alignment and phase refinement; alignment is not rerun with the offset. Timing zero is the clean baseline. Contrast uses `mean(window) + alpha*(window-mean(window)) + noise`; even alpha=1 includes added noise. All perturbations act in raw luma units before the existing per-bit normalization, including its 0.5-luma dynamic-range cutoff. Classic uses the strict four-sample rule `x0+x1 > x2+x3` on the same perturbed float signal; both CNNs receive its identical normalized INT8 bytes and use their own output quantization at probability >=0.5.

Noise estimator: partition each clean aligned 192-sample window into 96 adjacent two-sample half-bits. Fit a separate constant to each pair. Pool squared residuals over all session windows and divide by residual degrees of freedom (one per pair): `sigma_session = sqrt(mean((x[2k]-x[2k+1])**2)/2)`. This is the within-half-bit residual estimate, without subtracting a sessionwide or bitwide trend. It can include transition/interpolation effects and deterministic within-half-bit slope; correlated resampling can bias an IID sensor-noise interpretation. It is an operational residual noise scale, not a calibrated sensor noise measurement.

SNR definition: for each clean window, average the two samples in each half-bit. Let `A = sqrt(mean_bits(((first_half_mean-second_half_mean)/2)**2))`, the RMS Manchester half-bit excursion about the bit midpoint. Added Gaussian noise has `sigma = A * 10**(-SNR_dB/20)`, so `SNR_dB = 10*log10(A**2/sigma**2)`. This is the SNR of the added noise relative to clean-window half-bit amplitude; existing capture noise is retained, not included in the specified added-noise denominator. No TX labels enter either amplitude or noise estimation.

Five fixed seeds are logged. Each family uses independent draws, while the same standardized draws are paired across points within that family. Models and Classic are paired on exactly the same perturbed window. Gaussian draws are independent in the 20 Hz resampled domain. `config.json` records input/script/model SHA256 values, quantization, session noise scales, seeds, and rates.

Captions for `ber_vs_timing_offset.png`, `ber_vs_contrast.png`, and `ber_vs_snr.png` (also PDF): BER versus residual timing offset, contrast factor, or added-noise SNR, respectively, for the repeat-3 sessions; left panel 1–7 m, right panel 1–5 m. Error bars show two-sided 95% Clopper–Pearson intervals. Zero-error points appear at the CI upper bound with open markers; they do not represent an observed positive BER. Connected lines are guides between tested points. Intervals use nominal binomial bit counts; temporal correlation and repeated use of captured windows mean they are not independent-capture confidence intervals.

Training-plot captions: solid and dashed curves denote training and validation binary cross-entropy; stars mark 1-based `argmin(val_loss)`, read from history without retraining. Per-condition plots use the same CP/open-marker convention. Best epochs are appended to repeat/LODO summaries. Model deployment and autonomous alignment under physical timing/noise changes still require hardware verification; this analysis only perturbs captured signals offline.
